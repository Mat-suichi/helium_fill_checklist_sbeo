# Helium Fill Checklist（ヘリウム充填チェックシート）
https://mat-suichi.github.io/helium_fill_checklist_sbeo/


YR-70V レギュレータでのヘリウム充填を、一人で手順を確認しながら進めるためのツールです。

- 最初にボンベ情報（本数・容積・初期圧）を入力すると、ボンベごとに「一次圧がいくつになったら出口を閉めるか」を出します。
- 充填中は今やる手順を1つずつ大きく表示します。
- 最後に体重計で浮力を測り、想定上昇速度を出します。

見た目は SBEO Predictor に合わせていますが、別のフォルダの別のツールで、互いに影響しません。

## PC で開く（ダブルクリック）

`index.html` をダブルクリックするだけです。Edge か Chrome で開きます。インストールもインターネット接続も要りません。

入力した内容はブラウザに自動保存されます。閉じても、次に同じ `index.html` を開くと続きから使えます。

## iPad で開く（オフライン対応）

iPad の Safari は、ファイルアプリに置いた HTML ではプログラムが動きません。そのため一度だけ、このフォルダをインターネット上（https）に置いて、iPad のホーム画面に追加します。追加した後は、機内モードでも開けます。

### 1. GitHub Pages に置く（無料・最初の1回だけ）

1. https://github.com にログインし、右上の「＋」→「New repository」を選びます。名前は例えば `helium-fill-checklist` にして、**Public** で作成します。
2. 作成したリポジトリで「uploading an existing file」（または「Add file」→「Upload files」）を開きます。
3. このフォルダの中身を**フォルダごと**ドラッグして「Commit changes」を押します。
   - 置くもの：`index.html`・`manifest.webmanifest`・`sw.js`・`css`・`js`・`icons`
   - `tests`・`package.json`・`README.md` は置いても置かなくても構いません。
4. 「Settings」→「Pages」を開き、「Branch」を `main`・`/ (root)` にして「Save」を押します。
5. 1〜2分待つと、`https://<GitHubのユーザー名>.github.io/helium-fill-checklist/` で開けるようになります。

Public にすると誰でもこのページを見られます。ただし入れているのは手順とガス計算式だけで、入力した値や記録はそれぞれの端末の中にしか保存されません。

### 2. iPad のホーム画面に追加する

1. iPad の **Safari** で上の URL を開きます（Chrome などではオフラインにできません）。
2. 共有ボタン（□↑）→「ホーム画面に追加」→「追加」を押します。
3. ホーム画面の「充填チェック」アイコンから**一度開きます**（ネットにつながった状態で）。これでオフライン用の保存がされます。
4. 確認のため機内モードにして、アイコンから開けることを確かめます。

以後は**必ずホーム画面のアイコンから**開いてください。Safari のタブで開いた場合とホーム画面から開いた場合とでは、保存される記録が別になります。

### 3. 更新したいとき

GitHub の同じ場所にファイルをアップロードし直します（同じ名前のファイルは上書きされます）。iPad はネットにつながった状態でアイコンを開くと裏で新しい版を取り込み、**次に開いたとき**に反映されます。

## 使い方

手順は「全シーケンス表_2026（後改）」の A〜H に合わせています（現地入り → A 荷姿準備 → B バルーン準備 → C 充填準備 → D ボンベごとの充填 → F 浮力確認 → G 締結 → H 放球）。

1. **① ボンベ**
   - 本数と、各ボンベの容積・初期圧を入れます。途中から始めるときは、使い終わったボンベの「実測開始・実測終了」も入れます。空欄なら予定どおり使ったものとして扱います。
   - 「開始位置」で、始める節と手順を選んで「ここから始める ▶」を押します。
2. **② 手順**
   - 上の節チップ（当日 A B C D1 D2… F G H）を押すと、その節へ移動します。
   - 今の手順が大きく出るので、終わったら **✓ 完了** を押します。表の備考も小さく出ます。
   - 下の一覧の行を押してもチェックでき、節の「ここから開始」で開始位置を変えられます。
   - 最後のボンベはレギュレータを外さず（E-3）、ホースを入れたまま F 浮力確認に進みます。
3. **F 浮力確認**
   - 体重を2回入れると、計算との差（±5%）と想定上昇速度が出ます。
   - 足りなければ「③ 浮力」の追加充填をします。レギュレータの付け直しやホースの締結は要らず、同じボンベで「開栓 → 二次圧調整 → 目標の一次圧まで充填 → 脱圧」をもう1回やります。終わったら F-2 を測り直します。
4. **記録**：チェックした時刻・入力した圧力・浮力測定・追加充填が残ります。「記録をコピー」「CSV」で書き出してください。

画面を開いている間は、iPad や PC がスリープしないようにしています（対応しているブラウザのみ）。

## 計算

- 必要ガス量・ボンベから出る量・目標一次圧は `js/calc/balloon-gas.js` で計算します。式は学生気球ガス計算シート 2026 / gas_calc_2026.py に準拠しています（断熱・ポリトロープ・準静的）。
- 実測の開始・終了一次圧を入れると、そのボンベで入った量を求め、残りを次のボンベ以降に割り振り直します。
- 浮力の計算は次のとおりです。
  - 全浮力 ＝（①−②）＋ 気球質量 ＋ 一緒に持っている物
  - 純浮力 ＝ 全浮力 − 総重量
  - 想定上昇速度 v = k√L / (W+L)^(1/3)

`js/calc/balloon-gas.js` は tawhiri_based_sim にある同名ファイルのコピーです。計算式を変えたときは、こちらも手で揃えてください。手順の文章は `js/fill/fill-checklist-core.js` の `STEPS` で変更できます。
